  • The Driver Station draws HTML telemetry with Android's Html.fromHtml: <b>, <tt> and <font color> work, and runs of spaces collapse to one, so padding uses &nbsp;.
    • 
    
  • The Driver Station has no tables or columns, so each field row and the readout beside it are one telemetry line, and the side-by-side numbers are one monospace line. If a line is too long for the screen it wraps and the field breaks up; shrink FieldDiagram.COLS or the side text if that happens on the real Driver Hub.
    • 
    
  • Field: seen from our driver station, our wall at the bottom. Each row is 12 in and each column 6 in. The arrow is the robot, pointing the way it faces (8 directions). Each hive is a ====== bar in its alliance's color; ours has a bold O on the up cell, the one to shoot at. Orange @ marks the four flowers on the walls.
    • 
    
  • If the robot's row looks shifted on the Driver Hub, its monospace font has no arrow characters. Switch FieldDiagram.ARROWS to ^ < v >.
